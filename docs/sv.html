Orion kompilerar till LLVM IR och därefter till en nativ binär. Indentering gör block. Det finns ingen null och inga undantag. Varje kodblock nedan är ett helt program, och alla kompileras av tools/docs_check.sh — slutar ett exempel här fungera säger bygget ifrån. Kommentarerna i koden är på engelska, som resten av repot.

1. Hej

fn main() -> int:
    print_line("hello")
    0

Bygg och kör:

orbit run hello.or

Ett blocks värde är dess sista uttryck, så något return behövs inte — men det finns för att lämna tidigt. Det main returnerar blir processens exitkod.

Inget projekt, ingen konfiguration, ingen utdatasökväg att namnge. orbit build hello.or lämnar en körbar hello bredvid källan. För något större skapar orbit new myapp ett projekt, och samma run, build och test fungerar där inne.

2. Namn

fn main() -> int:
    x = 41            # bound once
    mut total = 0     # this one changes
    total = total + x
    total += 1
    ready = true      # bool: true / false, with and / or / not
    ratio = 1.5       # float
    if ready and not (ratio > 2.0) then total else 0

Ett vanligt = binder ett nytt namn. mut markerar ett du tänker skriva om, och kompilatorn håller dig till det. Typer härleds; skriv ut en när du vill ha den kontrollerad, som i mut n: int = 0. Typerna du får gratis är int, float, bool och Text. const LIMIT = 10 namnger en konstant och type Meters = int namnger en befintlig typ.

3. Text

fn main() -> int:
    name = "world"
    n = 3
    print_line("hello {name}, {n} times, {n * 2} in total")
    print_line("a literal brace: \{ and \}")
    0

Varje strängliteral är en interpolation. Ett hål {...} tar vilket uttryck som helst, inte bara ett namn. En riktig klammer skrivs \{. Tre eller fler delar blir en enda join, så att bygga en rad i en loop kostar dig inte tyst en allokering per bit.

4. Förgrening

fn classify(n: int) -> Text:
    match:
        n < 0:  "negative"
        n == 0: "zero"
        else:   "positive"

fn main() -> int:
    print_line(classify(0 - 5))
    label = if 1 == 1 then "yes" else "no"
    print_line(label)
    0

match: utan subjekt är en kedja av villkor där första sanna armen vinner. Det är vad du använder i stället för else if. if c then a else b är enradsformen; den indenterade if c: / else: är blockformen.

5. Loopar

fn main() -> int:
    mut sum = 0
    loop i in 0..<5:                          # 0 1 2 3 4
        sum += i
    loop i in 1..=3:                          # 1 2 3
        sum += i
    doubled = loop x in [1, 2, 3]: x * 2      # [2, 4, 6]
    big = loop x in [1, 2, 3] where x > 1: x  # [2, 3]
    loop:
        break
    sum + len(doubled) + len(big)

loop är det enda iterationsordet. I satsposition loopar det; i uttrycksposition samlar det varje kroppsvärde i en lista, och därifrån kommer map och filter — where är filtret. 0..<5 utesluter slutet, 1..=3 inkluderar det, och ett naket loop: går tills break.

6. Listor och mappar

fn main() -> int:
    xs = [10, 20, 30]
    ys = push(xs, 40)          # push returns a new list
    m = {"a": 1, "b": 2}
    print_line("first={xs[0]} len={len(ys)} b={get(m, "b")}")
    xs[0] + len(ys)

push kopierar. Det håller värdesemantiken ovillkorlig, och det betyder att x = push(x, v) i en tät loop är kvadratisk — för en het ackumulator är push_mut den auditerade vägen att lägga till på plats. Indexera med xs[0]; at, len, get och has är funktionsformerna, alla inbyggda och utan import.

7. Typer

type Player: name: Text, hp: int

type Shape:
    Circle(int)
    Rect(int, int)

fn area(s: Shape) -> int:
    match s:
        Circle(r) -> 3 * r * r
        Rect(w, h) -> w * h

fn divmod(a: int, b: int) -> (int, int):
    (a / b, a % b)

fn main() -> int:
    p = Player{name: "Hero", hp: 100}
    q, r = divmod(17, 5)
    print_line("{p.name} has {p.hp} hp; 17/5 is {q} rem {r}")
    area(Shape.Rect(6, 7))

Ett nyckelord för båda formerna. Fält på en rad ger en post, som nås med p.name. Varianter ger en summatyp, som byggs Shape.Rect(6, 7) och läses med match, som kontrolleras för uttömmande täckning. _ är uppsamlingsmönstret, och if let Circle(r) = s: tar enfallskontrollen utan en hel match.

En tupel (a, b) är en anonym struct, så varje plats behåller sin egen typ och (int, Text) är ett riktigt par. Så returnerar en funktion mer än en sak, och q, r = divmod(17, 5) plockar isär dem. Tupelmönster fungerar i match också.

8. Funktioner, lambdor, orbs

use text
use iter

fn main() -> int:
    words = split("alpha,beta,gamma", ",")
    lengths = loop w in words: len(w)
    double = fn(x): x * 2
    print_line("words={len(words)} letters={sum(lengths)}")
    double(21)

Ett bibliotek är en orb: use text tar in en, och pub fn är vad en orb exporterar. Varje orb är sin egen namnrymd. En lambda är fn(params): body och fångar det den behöver. Varje funktion kan också anropas metodstil, så trim(s) och s.trim() är samma anrop.

9. När det går fel

type Res<T>:
    Ok(T)
    Err(Text)

fn safe_div(a: int, b: int) -> Res<int>:
    if b == 0:
        Res.Err("divide by zero")
    else:
        Res.Ok(a / b)

fn calc(x: int) -> Res<int>:
    v = safe_div(84, x)?      # unwrap, or return the Err
    Res.Ok(v * 2)

fn main() -> int:
    require 1 == 1            # traps if false
    defer print_line("cleanup runs last")
    match calc(2):
        Ok(v) -> v
        Err(_) -> 0

Det finns ingen null att glömma kontrollera och inget undantag att glömma fånga. Fel är ett värde: ge det en variant, så packar ? antingen upp det goda fallet eller skickar det dåliga vidare till din anropare. Typer tar parametrar, så en enda Res<T> täcker varje nyttolast i stället för en per typ. require och ensure är kontrakt som kontrolleras vid körning och smäller på ett falskt villkor. defer körs vid blockets slut, senast registrerad först, och före varje return.
