Bring an orb in with use text. Any function is also callable method-style, so trim(s) and s.trim() are the same call. The built-ins the guide uses (print_line, len, push, get, file and CLI functions) need no use at all.

text

common text helpers callable via method-call syntax.

is_empty(t: text) -> truth
example is_empty("")
example not is_empty("x")
byte_count(t: text) -> number
example byte_count("åsa") is 4
starts_with(t: text, prefix: text) -> truth
example starts_with("hello", "he")
ends_with(t: text, suffix: text) -> truth
example ends_with("hello", "lo")
repeat(t: text, n: number) -> text

Repeat t n times. Returns "" if n <= 0.

example repeat("ab", 3) is "ababab"
reverse(t: text) -> text

Reverse by CHARACTER (UTF-8-aware): a multibyte sequence keeps its byte order, so reversing Swedish never produces invalid UTF-8.

example reverse("abc") is "cba"
example reverse("åsa") is "aså"
upper(t: text) -> text

Upper-case, code point by code point.

example upper("hej") is "HEJ"
example upper("åsa är glad") is "ÅSA ÄR GLAD"
example upper("ελληνικά") is "ΕΛΛΗΝΙΚΆ"
example upper("привет") is "ПРИВЕТ"
lower(t: text) -> text

Lower-case, code point by code point.

example lower("HEJ") is "hej"
example lower("ÅSA ÄR GLAD") is "åsa är glad"
example lower("ΕΛΛΗΝΙΚΆ") is "ελληνικά"
example lower("ПРИВЕТ") is "привет"
trim(t: text) -> text

Remove leading and trailing ASCII whitespace (space, tab, newline, CR). trim(" hi ") -> "hi"

example trim("  hi  ") is "hi"
join(parts: [text], sep: text) -> text

Join a list of pieces with sep between them. join(["a", "b", "c"], "-") -> "a-b-c" Joined by halves, not one at a time. Adding a piece to the end of a growing text copies everything already in it, so a thousand pieces copy the whole result a thousand times - the cost grows with the SQUARE of how many there are, which is why building one big text out of many small ones was always the slow part of anything that serialises. Pairing them up instead means each byte is copied about log2(n) times: a display list of a hundred and fifty pieces went from copying a megabyte to copying a hundred kilobytes.

example join(["a", "b", "c"], "-") is "a-b-c"
example join([], "-") is ""
example join(["only"], "-") is "only"
split(t: text, sep: text) -> [text]

Split t on every occurrence of sep, returning the pieces. split("a,b,c", ",") -> ["a", "b", "c"] An empty sep yields the whole string as a single piece.

example length(split("a,b,c", ",")) is 3
replace(t: text, from: text, to: text) -> text

Replace every occurrence of from with to - split on from, rejoin with to. An empty from returns t unchanged. replace("a,b,c", ",", "; ") -> "a; b; c"

example replace("a,b", ",", "; ") is "a; b"
index_of(t: text, sub: text) -> number

First byte index of sub in t, or -1 if absent. Empty sub -> 0. Where sub starts, counted in CHARACTERS, or -1. The search itself walks BYTES - UTF-8 is self-synchronising, so a well-formed needle can only match at a character boundary - and the byte offset is converted at the end. It reads the text where it lies. bytes_of would copy every byte into an eight-byte slot first, which for a megabyte of source is eight megabytes to find one word.

example index_of("hello", "ll") is 2
example index_of("hello", "zz") is 0 - 1
example index_of("räksmörgås", "ö") is 5
pad_left(t: text, width: number, pad: text) -> text

Pad t on the left with pad until it is at least width bytes wide.

example pad_left("7", 3, "0") is "007"
pad_right(t: text, width: number, pad: text) -> text

Pad t on the right with pad until it is at least width bytes wide.

example pad_right("7", 3, "0") is "700"
lines(t: text) -> [text]

Split t into lines on '\n'.

int_from_text(t: text) -> number

The integer written at the start of t: an optional -, then digits. Stops at the first non-digit; no digits at all is 0. For CLI arguments and simple protocols - not a validator.

example int_from_text("42") is 42
example int_from_text("-7") is 0 - 7
example int_from_text("12ab") is 12
example int_from_text("x") is 0

list

everyday integer-list helpers that don't need a closure.

range(n: number) -> [number]

[0, 1, …, n-1]. Empty for n <= 0.

example length(range(4)) is 4
reversed(xs: [number]) -> [number]

A new list with the elements in reverse order.

example reversed([1, 2, 3])[0] is 3
includes(xs: [number], v: number) -> truth

true if v appears in xs. (Named includes to avoid the built-in contains, which is text-substring only.)

example includes([1, 2, 3], 2)
find(xs: [number], v: number) -> number

First index of v, or -1 if absent.

example find([5, 6], 6) is 1
example find([5, 6], 9) is 0 - 1
first(xs: [number]) -> number

First / last element, or 0 for an empty list.

example first([9, 8]) is 9
last(xs: [number]) -> number
example last([9, 8]) is 8
example last([9, 8]) is 8
max_of(xs: [number]) -> number

Largest / smallest element, or 0 for an empty list. (Named *_of to avoid num's two-argument max / min.)

example max_of([3, 42, 7]) is 42
min_of(xs: [number]) -> number
example min_of([3, 42, 7]) is 3
avg(xs: [number]) -> number

Integer average (sum / count), truncated. 0 for an empty list.

example avg([2, 4, 6]) is 4
concat(a: [number], b: [number]) -> [number]

a followed by b, as a new list.

example length(concat([1, 2], [3])) is 3
unique(xs: [number]) -> [number]

The elements of xs with later duplicates removed (first occurrence kept).

example length(unique([1, 2, 1, 3])) is 3
take(xs: [number], n: number) -> [number]

The first n elements (all of them if n >= len, none if n <= 0).

example length(take([1, 2, 3], 2)) is 2
drop(xs: [number], n: number) -> [number]

All but the first n elements.

example length(drop([1, 2, 3], 2)) is 1
filled(count: number, value: number) -> list of number

A list of count copies of one value - THE way to born a big buffer (a per-element push is a copy per element on backends without in-place growth; this is one allocation everywhere). filled_number stood next to this with the SAME four lines - it was the float version back when the two number words were separate. number picks, so one is enough.

example length(filled(3, 0)) is 3
example filled(3, 7)[2] is 7
example filled(2, 1.5)[0] is 1.5

num

the small integer helpers every program reaches for.

abs(x: number) -> number

Absolute value.

example abs(0 - 5) is 5
min(a: number, b: number) -> number

The smaller of two values.

example min(3, 7) is 3
max(a: number, b: number) -> number

The larger of two values.

example max(3, 7) is 7
clamp(x: number, lo: number, hi: number) -> number

Constrain x to the range [lo, hi].

example clamp(15, 0, 10) is 10
sign(x: number) -> number

-1, 0, or 1 by the sign of x.

example sign(0 - 9) is 0 - 1
gcd(a: number, b: number) -> number

Greatest common divisor (Euclid). gcd(0, 0) is 0.

example gcd(12, 18) is 6
parse(t: text) -> number

Parse a base-10 integer out of text. A leading '-' negates; digits are read left to right and any non-digit is skipped. parse("") is 0. parse("42") -> 42 parse("-7") -> -7 Pairs with split: split("3,4,5", ",") then parse each piece.

example parse("42") is 42
ipow(base: number, exp: number) -> number

Integer power (ipow): base^exp for exp >= 0. Negative exp yields 0. ipow(2, 10) -> 1024

example ipow(2, 10) is 1024
is_even(n: number) -> truth

1 if n is even, else 0.

example is_even(4)
is_odd(n: number) -> truth

1 if n is odd, else 0.

example is_odd(7)
parse_float(t: text) -> float

Parse a float out of text: optional '-', integer part, optional '.fraction', optional 'e'/'E' exponent (with optional sign). Non-numeric tails stop the scan. parse_float("") is 0.0. parse_float("3.14") -> 3.14 parse_float("-2.5e3") -> -2500.0

example parse_float("1.5") is 1.5
with_decimals(x: float, decimals: number) -> text

x as text with a fixed number of decimals - the one formatting ask plain to_text cannot answer.

example with_decimals(3.14159, 2) is "3.14"
example with_decimals(2.5, 0) is "2"
example with_decimals(1.0, 3) is "1.000"

iter

functional list operations, powered by closures.

Types

order_of: less: function

Functions

each<T>(xs: [T], f: function) -> [number]

Apply f to every element, collecting the results.

example each([1, 2, 3], (x): x * 2)[1] is 4
keep<T>(xs: [T], pred: function) -> [T]

Keep the elements for which pred(x) holds. Result keeps the element type.

example length(keep([1, 2, 3, 4], (x): x > 2)) is 2
combine<T>(xs: [T], init: number, f: function) -> number

Fold left: acc starts at init, then acc = f(acc, x) for each element.

example combine([1, 2, 3], 0, (a, b): a + b) is 6
any<T>(xs: [T], pred: function) -> truth

true when pred(x) holds for at least one element.

example any([1, 5, 9], (x): x > 8)
example not any([1, 2], (x): x > 8)
all<T>(xs: [T], pred: function) -> truth

true when pred(x) holds for every element (vacuously true when empty).

example all([2, 4], (x): x % 2 is 0)
example not all([2, 5], (x): x % 2 is 0)
find_index<T>(xs: [T], pred: function) -> number

Index of the first element where pred(x) holds, or -1 if none match.

example find_index([1, 9, 3], (x): x > 5) is 1
count<T>(xs: [T], pred: function) -> number

How many elements satisfy pred.

example count([1, 9, 3, 7], (x): x > 5) is 2
sum(xs: [number]) -> number

Sum of every element (0 for an empty list). No closure - the workhorse combine(xs, 0, function(a, b): a + b) written once.

example sum([1, 2, 3]) is 6
example sum([40, 2]) is 42
max_by(xs: [number], key: function) -> number

The element with the largest key(x). Ties keep the earlier element. Returns 0 for an empty list.

example max_by([1, 9, 3], (x): x) is 9
min_by(xs: [number], key: function) -> number

The element with the smallest key(x). Ties keep the earlier element. Returns 0 for an empty list.

example min_by([4, 2, 8], (x): x) is 2
sorted<T>(xs: [T], order: order_of) -> [T]

Generic: works on ANY element type, because the ORDER comes in as a capability record (requires order) rather than being baked into the element type. sort_by(xs, less_fn) stays for the plain int case.

example sorted([3, 1, 2], order_of{less: (a, b): a < b})[0] is 1
sort_by(xs: [number], less: function) -> [number]

The int-typed form (kept: the common case, no capability record needed).

example sort_by([3, 1, 2], (a, b): a < b)[0] is 1

json

parse and build JSON.

Types

Json = JNull | JBool(truth) | JNum(number) | JStr(text) | JArr([Json]) | JObj([text], [Json]) # parallel keys and values

Functions

json_parse(src: text) -> table
example json_has(json_parse("\{\"k\": 1\}"), "k")
json_obj(o: table, key: text) -> table
example json_has(json_obj(json_parse("\{\"o\": \{\"k\": 1\}\}"), "o"), "k")
json_text(o: table, key: text) -> text
example json_text(json_parse("\{\"s\": \"hi\"\}"), "s") is "hi"
json_whole(o: table, key: text) -> number

A WHOLE number out of the dynamic reader, and the name says so: a table slot is one machine word, and this side of the orb puts a whole number in it. 1.5 in the source reads back as 1 - the scanner consumes the fraction and drops it, which is what the LSP wants (ids, lines, characters are all whole) and what nothing else should rely on. The WRITING side has no such limit: jnum(1.5) is a JSON number and serializes as one.

example json_whole(json_parse("\{\"n\": 7\}"), "n") is 7
example json_whole(json_parse("\{\"x\": 1.5\}"), "x") is 1
json_list(o: table, key: text) -> [table]
example length(json_list(json_parse("\{\"xs\": [1, 2]\}"), "xs")) is 2
json_has(o: table, key: text) -> truth
example json_has(json_parse("\{\"a\": 1\}"), "a")
json_escape(s: text) -> text

Escape a Text for embedding in JSON output. Single pass; the byte list is turned into text once at the end.

example json_escape("a\"b") is "a\\\"b"
jnull() -> Json
example json_stringify(jnull()) is "null"
jbool(b: truth) -> Json
example json_stringify(jbool(true)) is "true"
jnum(n: number) -> Json
example json_stringify(jnum(0 - 5)) is "-5"
example json_stringify(jnum(1.5)) is "1.5"
jstr(s: text) -> Json
example json_stringify(jstr("hi")) is "\"hi\""
jarr(items: [Json]) -> Json
example json_stringify(jarr([])) is "[]"
jobj(keys: [text], vals: [Json]) -> Json
example json_stringify(jobj([], [])) is "\{\}"
json_stringify(j: Json) -> text

Serialize a Json value to compact JSON text.

example json_stringify(jnum(42)) is "42"
example json_stringify(jarr([jnum(1), jnum(2)])) is "[1,2]"

sqlite

a real SQL database in one file, no server.

db_open(path: text) -> number uses files = sq_open(path)

Open (or create) the database file. A handle, or -1 - ask db_error(-1) for nothing; a failed open names its reason on the handle it tried. no example: opens a file on disk - proven by tools/sqlite_test.sh

db_close(db: number) -> number uses files = sq_close(db)
db_run(db: number, sql: text) -> truth uses files = sq_exec(db, sql, "") is 0

Run SQL that yields no rows (CREATE, INSERT, UPDATE, DELETE). false on error - db_error(db) says why. no example: writes to a database file - proven by tools/sqlite_test.sh

db_run_with(db: number, sql: text, params: [text]) -> truth uses files = sq_exec(db, sql, join_params(params)) is 0

Same, with ? placeholders bound from params, in order. The ONLY way user input should ever reach SQL. no example: writes to a database file - proven by tools/sqlite_test.sh

db_rows(db: number, sql: text) -> [text] uses files

All result rows, one text per row. Split a row's cells with columns(). Empty result is []; on error it is also [] and db_error(db) says why. no example: reads a database file - proven by tools/sqlite_test.sh

db_rows_with(db: number, sql: text, params: [text]) -> [text] uses files
columns(row: text) -> [text]

One row's cells. NULL comes back as "".

example length(columns("a")) is 1
db_one(db: number, sql: text) -> text uses files

The first cell of the first row - the shape of COUNT(*) and friends. "" when the query gave nothing. no example: reads a database file - proven by tools/sqlite_test.sh

db_error(db: number) -> text uses files = sq_error(db)

Why the last call on this handle failed, "" when it did not. no example: database state - proven by tools/sqlite_test.sh

db_changes(db: number) -> number uses files = sq_changes(db)

Rows changed by the last INSERT/UPDATE/DELETE. no example: database state - proven by tools/sqlite_test.sh

db_last_id(db: number) -> number uses files = sq_last_id(db)

The rowid the last INSERT got. no example: database state - proven by tools/sqlite_test.sh

time

clock time for humans: unix seconds and formatted dates.

now_unix() -> number uses clock = unix_now()

Seconds since 1970-01-01 UTC. no example: wall-clock dependent - proven by test_42_general_floor.or

local_time(unix_s: number, fmt: text) -> text

unix_s formatted with strftime codes, in the machine's local timezone.

example length(local_time(0, "%Y")) is 4
utc_time(unix_s: number, fmt: text) -> text

unix_s formatted with strftime codes, in UTC.

example utc_time(0, "%Y-%m-%d") is "1970-01-01"
example utc_time(86400, "%H:%M:%S") is "00:00:00"
timestamp() -> text uses clock = local_time(unix_now(), "%Y-%m-%d %H:%M:%S")

The common stamp, local: "2026-08-04 21:30:05". no example: wall-clock dependent - proven by test_42_general_floor.or

parse_utc(t: text) -> number

"YYYY-MM-DD" or "YYYY-MM-DD HH:MM:SS" (UTC) -> unix seconds. -1 when the text does not have that shape. The inverse of utc_time with the same formats - round-trips by construction.

example parse_utc("1970-01-01") is 0
example parse_utc("1970-01-02 00:00:00") is 86400
example parse_utc("not a date") is 0 - 1
example utc_time(parse_utc("2026-08-04 21:30:05"), "%Y-%m-%d %H:%M:%S") is "2026-08-04 21:30:05"

http

fetch and post over HTTP(S).

Types

reply = status: number | body: text

Functions

status_from_headers(header_dump: text) -> number

The status is read from curl's header dump (-D), not from stdout: the dump is a file of its own, so a stray stderr line can never corrupt it. With redirects (-L) the dump holds one block per hop - the LAST status line is the answer.

example status_from_headers("HTTP/1.1 200 OK") is 200
example status_from_headers("garbage") is 0
fetch(url: text) -> reply uses net, files

GET url. success(r) when the request went through AND the server said 2xx. no example: needs the network - proven by examples/demos/httpd.or + manual runs

post(url: text, content_type: text, payload: text) -> reply uses net, files

POST body to url with the given Content-Type. no example: needs the network - proven by manual runs

success(r: reply) -> truth

Did the request reach a server that answered success?

example success(reply{status: 200, body: ""})
example not success(reply{status: 404, body: ""})
example not success(reply{status: 0, body: ""})

net

blocking TCP, client and server.

connect(host: text, port: number) -> number uses net

--- client ---

example not ok(connect("127.0.0.1", 1))
send(sock: number, data: text) -> number uses net = tcp_send(sock, data)
recv(sock: number, maxlen: number) -> text uses net = tcp_recv(sock, maxlen)
close(sock: number) -> number uses net
example close(0 - 1) is 0
listen(port: number) -> number uses net

--- server --- Open a listening socket on port (loopback). -1 if the port is taken.

example close(listen(58499)) is 0
accept(server: number) -> number uses net = tcp_accept(server)
with_connection(host: text, port: number, body: function) -> number uses net

--- lifetime-safe forms --- The socket you cannot forget to close: the ORB owns the handle, runs your body with it, and closes on the way out (including when the body returns early - the close is a defer). This is the library-level shape of the scope-owned resource model (Tema 10); when the language gains handler-owned resources these become that, with the same call sites. answer = with_connection("127.0.0.1", 8080, (c): send(c, "hi")) The body gets the socket and returns a number; -1 means the connect failed. no example: needs a live peer - proven by examples/demos/httpd.or

with_listener(port: number, body: function) -> number uses net

The same for a listening socket: serve, hand the listener to the body, and close it however the body leaves. no example: binds a port - proven by test_42_net_scoped.or

set_timeout(sock: number, ms: number) -> number uses net = tcp_set_timeout(sock, ms)

Give up after ms milliseconds instead of blocking forever: accept then returns -1 and recv returns "" when the deadline passes. 0 restores blocking. Set it on a LISTENER before accept, or on a connection before recv - a server that cannot time out cannot do anything else. no example: needs a live socket - proven by test_42_net_timeout.or

accept_within(listener: number, ms: number) -> number uses net = tcp_accept_wait(listener, ms)

Wait up to ms for a client; -1 when nobody came. This is the one a server loop wants: it can time out, do other work, and come back. no example: needs a listener + timing - proven by test_42_net_timeout.or

connect_within(host: text, port: number, ms: number) -> number uses net

Connect, but give up after ms instead of blocking. Plain connect is the one socket call that cannot time out, and a blocked connect parks the whole PROCESS - so inside a task it freezes every other task too. That is not theoretical: ten clients against a server whose listen backlog was full deadlocked, because the connect that had to wait was holding the scheduler the acceptor needed. Inside a task, use this and sleep_task between tries.

example not ok(connect_within("127.0.0.1", 1, 50))
readable_within(sock: number, ms: number) -> truth uses net

Has sock got anything to read? Waits up to ms for it. This is the call that makes a task-per-connection server scale. Without it the only way to wait is recv with a short timeout, retried - and every attempt parks the whole PROCESS, so a round costs (waiting tasks x timeout). Here the task parks and the SCHEDULER waits for every parked socket in one select, so a round costs one wait however many tasks are in it. Outside a task it is an ordinary wait, so the same call is right in both places. no example: needs a live socket - proven by test_42_net_concurrent.or

timed_out(chunk: text) -> truth

Did a read time out (or the peer close)? Both surface as "".

example timed_out("")
example not timed_out("data")
ok(handle: number) -> truth

Did the call succeed? Reads better than comparing to -1 at every site.

example ok(0 - 1) is false
example ok(3)
udp(port: number) -> number uses net = udp_open(port)

A bound UDP socket, or -1. Port 0 picks an ephemeral one. no example: opens a socket - proven by test_42_udp_loopback.or

udp_send(sock: number, host: text, port: number, data: text) -> number uses net = udp_send_to(sock, host, port, data)

Send one datagram to host:port. Bytes sent, or -1. no example: sends on the network - proven by test_42_udp_loopback.or

udp_receive(sock: number, maxlen: number) -> text uses net = udp_recv_from(sock, maxlen)

One datagram as text ("" when nothing). Pair with readable_within for a deadline; ask udp_sender() right after for who sent it. no example: reads the network - proven by test_42_udp_loopback.or

udp_sender() -> text uses net = udp_last_sender()

"ip:port" of the last datagram udp_receive returned, "" before any. no example: network state - proven by test_42_udp_loopback.or

local_port(sock: number) -> number uses net = sock_local_port(sock)

The port a socket actually bound to - what listen(0)/udp(0) picked. no example: opens a socket - proven by test_42_udp_loopback.or

send_raw(sock: number, data: text) -> number uses net = tcp_send_len(sock, data)

Binary-safe send: the byte count comes from the text's length header, not a null scan - a JPEG survives intact. What a file server answers with. no example: sends on a socket - proven by folio (the image viewer)

os

CLI / OS primitives for self-hosted tools (orbit), under the names orbit already uses.

elapsed(start: number) -> number uses clock = now() - start

Milliseconds between now() and an earlier now() - timing metric. no example: wall-clock dependent - proven by tools/compile_bench.sh

read_file(p: text) -> text uses files = file_read(p)

orion-self builtins under orbit's names (file_read/argv/argc live in the compiler, not an orb - callable directly). no example: needs a file on disk - proven by test_42_file_stream.or

arg(i: number) -> text = argv(i)

write_file(p: text, c: text) -> number uses files

Public wrapper so other orbs can branch on the host without re-declaring the extern (a second declare in the bundle is an LLVM redefinition error). 0 = Windows, 1 = Linux, 2 = macOS.

example os_kind() >= 0
