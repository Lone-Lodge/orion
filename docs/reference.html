Bring an orb in with use text. Any function is also callable method-style, so trim(s) and s.trim() are the same call. The built-ins the guide uses (print_line, len, push, get, file and CLI functions) need no use at all.

text

common text helpers callable via method-call syntax.

is_empty(t: text) -> truth
byte_count(t: text) -> int
starts_with(t: text, prefix: text) -> truth
ends_with(t: text, suffix: text) -> truth
repeat(t: text, n: int) -> text

Repeat t n times.

reverse(t: text) -> text

Reverse by CHARACTER (UTF-8-aware): a multibyte sequence keeps its byte order, so reversing Swedish never produces invalid UTF-8.

upper(t: text) -> text

Upper-case, code point by code point.

lower(t: text) -> text

Lower-case, code point by code point.

characters(t: text) -> int

How many CHARACTERS (Unicode code points) the text holds - len counts bytes, and "åsa" is 4 bytes but 3 characters.

trim(t: text) -> text

Remove leading and trailing ASCII whitespace (space, tab, newline, CR).

join(parts: [text], sep: text) -> text

Join a list of pieces with sep between them.

split(t: text, sep: text) -> [text]

Split t on every occurrence of sep, returning the pieces.

replace(t: text, from: text, to: text) -> text

Replace every occurrence of from with to - split on from, rejoin with to.

index_of(t: text, sub: text) -> int

First byte index of sub in t, or -1 if absent.

pad_left(t: text, width: int, pad: text) -> text

Pad t on the left with pad until it is at least width bytes wide.

pad_right(t: text, width: int, pad: text) -> text

Pad t on the right with pad until it is at least width bytes wide.

lines(t: text) -> [text]

Split t into lines on '\n'.

list

everyday integer-list helpers that don't need a closure.

range(n: int) -> [int]

[0, 1, …, n-1].

reversed(xs: [int]) -> [int]

A new list with the elements in reverse order.

includes(xs: [int], v: int) -> truth

true if v appears in xs.

find(xs: [int], v: int) -> int

First index of v, or -1 if absent.

first(xs: [int]) -> int

First / last element, or 0 for an empty list.

last(xs: [int]) -> int
max_of(xs: [int]) -> int

Largest / smallest element, or 0 for an empty list.

min_of(xs: [int]) -> int
avg(xs: [int]) -> int

Integer average (sum / count), truncated.

concat(a: [int], b: [int]) -> [int]

a followed by b, as a new list.

unique(xs: [int]) -> [int]

The elements of xs with later duplicates removed (first occurrence kept).

take(xs: [int], n: int) -> [int]

The first n elements (all of them if n >= len, none if n <= 0).

drop(xs: [int], n: int) -> [int]

All but the first n elements.

clamp(x: int, lo: int, hi: int) -> int

Constrain x to the range [lo, hi].

-1, 0, or 1 by the sign of x.

Greatest common divisor (Euclid).

1 if n is even, else 0.

is_odd(n: int) -> truth

1 if n is odd, else 0.

Absolute value of a float.

The smaller / larger of two floats.

fmax(a: float, b: float) -> float

Constrain a float to [lo, hi].

parse_float(t: text) -> float

Parse a float out of text: optional '-', integer part, optional '.fraction', optional 'e'/'E' exponent (with optional sign).

iter

Types

order_of: less: fn

Functions

Keep the elements for which pred(x) holds.

combine<T>(xs: [T], init: int, f: fn) -> int

Fold left: acc starts at init, then acc = f(acc, x) for each element.

Sum of every element (0 for an empty list).

min_by(xs: [int], key: fn) -> int

The element with the smallest key(x).

Generic: works on ANY element type, because the ORDER comes in as a capability record (requires order) rather than being baked into the element type.

sort_by(xs: [int], less: fn) -> [int]

The int-typed form (kept: the common case, no capability record needed).

net

blocking TCP, client and server.

connect(host: text, port: int) -> int uses net

--- client ---

send(sock: int, data: text) -> int uses net = tcp_send(sock, data)

no example: needs a live peer - proven by test_42_net_loopback.or

recv(sock: int, maxlen: int) -> text uses net = tcp_recv(sock, maxlen)

no example: needs a live peer - proven by test_42_net_timeout.or

close(sock: int) -> int uses net
listen(port: int) -> int uses net

--- server --- Open a listening socket on port (loopback).

accept(server: int) -> int uses net = tcp_accept(server)

no example: blocks for a client - proven by test_42_net_loopback.or

with_connection(host: text, port: int, body: fn) -> int uses net

--- lifetime-safe forms --- The socket you cannot forget to close: the ORB owns the handle, runs your body with it, and closes on the way out (including when the body returns early - the close is a defer).

with_listener(port: int, body: fn) -> int uses net

The same for a listening socket: serve, hand the listener to the body, and close it however the body leaves.

set_timeout(sock: int, ms: int) -> int uses net = tcp_set_timeout(sock, ms)

Give up after ms milliseconds instead of blocking forever: accept then returns -1 and recv returns "" when the deadline passes.

accept_within(listener: int, ms: int) -> int uses net = tcp_accept_wait(listener, ms)

Wait up to ms for a client; -1 when nobody came.

timed_out(chunk: text) -> truth

Did a read time out (or the peer close)? Both surface as "".

ok(handle: int) -> truth

Did the call succeed? Reads better than comparing to -1 at every site.

os

CLI / OS primitives for self-hosted tools (orbit), under the names orbit already uses.

elapsed(start: int) -> int uses clock = now() - start

Milliseconds between now() and an earlier now() - timing metric.

read_file(p: text) -> text uses files = file_read(p)

orion-self builtins under orbit's names (file_read/argv/argc live in the compiler, not an orb - callable directly).

arg(i: int) -> text = argv(i)

no example: depends on the process command line - proven by orbit

arg_count() -> int = argc()

no example: depends on the process command line - proven by orbit

write_file(p: text, c: text) -> int uses files
os_kind() -> int

Public wrapper so other orbs can branch on the host without re-declaring the extern (a second declare in the bundle is an LLVM redefinition error).

run_command(cmd: text, args: [text]) -> int = sys_run(os_join(os_quote(win_path(cmd)), args, 0))

no example: runs a child process - proven by orbit itself (build_orbit.sh)

run_command_quiet(cmd: text, args: [text]) -> int = sys_run_quiet(os_join(os_quote(win_path(cmd)), args, 0))

no example: runs a child process - proven by orbit itself

capture_stdout(cmd: text, args: [text]) -> text = capture(os_join(os_quote(cmd), args, 0))

no example: runs a child process - proven by tools/lsp_test.sh

path_join(a: text, b: text) -> text

---- paths ----

path_parent(p: text) -> text
list_dir(dir: text) -> [text] uses files = split(orion_dir_list(dir), "\n")

no example: depends on the filesystem - proven by tools/orbstat.or

list_dirs(dir: text) -> [text] uses files = split(orion_dir_subdirs(dir), "\n")

no example: depends on the filesystem - proven by tools/orbstat.or

arguments() -> [text]

The command line as ONE list of text - arguments() replaces argc()/argv(i) (the literal C names).

async

cooperative async helpers built on the new timing primitives.

sleep_until(deadline_ms: int) uses clock

Sleep until the monotonic clock reaches deadline_ms.

delay(duration_ms: int) uses clock

Sleep for at least duration_ms.

deadline_from_now(offset_ms: int) -> int uses clock

Return the monotonic clock value offset_ms from now.

past_deadline(deadline_ms: int) -> truth uses clock

Did deadline_ms already pass? Plain comparison helper for readability in event loops.

time_left(deadline_ms: int) -> int uses clock

Number of ms remaining until deadline_ms, clamped to 0 if past.

timers_new() -> [int]

Build an empty timer queue.

add_timer(timers: [int], offset_ms: int) -> [int]

Push a timer that fires offset_ms from now.

next_due(timers: [int]) -> int

Earliest deadline in the queue, or -1 if empty.

count_due(timers: [int]) -> int

How many timers have already fired (deadline <= now)?

wait_next(timers: [int]) uses clock

Sleep until the next deadline fires.

spawn(f: fn, arg: int) -> int = orion_task_spawn(f, arg)

Start a task.

await(id: int) -> int = orion_task_await(id)

Run the scheduler until this task finishes, then take its result.

yield_now() -> int = orion_task_yield()

Give the scheduler a turn.

run_all() -> int = orion_task_run_all()

Drive every ready task to completion; returns how many are finished.

task_state(id: int) -> int = orion_task_state(id)

0 = no such task, 1 = ready, 2 = running, 3 = finished (result not taken yet).

task_count() -> int = orion_task_live_count()

no example: needs the running task scheduler - proven by test_42_async_interleave.or

is_done(id: int) -> truth = orion_task_state(id) is 3

no example: needs the running task scheduler - proven by test_42_async_interleave.or

sleep_task(ms: int) -> int = orion_task_sleep(ms)

Wait ms WITHOUT holding the scheduler.

ask(handler: fn, arg: int) -> int = orion_ms_perform(handler, arg)

Inside a task: hand control to handler, which may resume this point once and then keep working.

resume_with(v: int) -> int = orion_ms_resume(v)

Inside such a handler: run the rest of the task with v, and get its result.

resumable_ok() -> truth = orion_ms_supported() is 1

no example: needs the running task scheduler - proven by test_42_async_interleave.or

timer

deterministic tick-based timers.

Start (or restart) a timer running toward dur_ms.

timer_stop(id: text)

Cancel a running timer (elapsed is kept for inspection).

timer_reset(id: text)

Rewind to 0 and keep running toward the same duration.

timer_tick(id: text, dt_ms: int) -> int

Advance by dt_ms.

timer_elapsed(id: text) -> int
timer_remaining(id: text) -> int
timer_progress(id: text) -> int

Progress as permille (0..1000), clamped.

timer_done(id: text) -> truth

1 once elapsed has reached the duration.

timer_active(id: text) -> truth

true while the timer is running (started, not yet completed or stopped).

timer_every(id: text, period_ms: int, dt_ms: int) -> int

Accumulate dt_ms and report how many whole periods elapsed this tick.
