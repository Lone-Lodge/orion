Orion compiles to LLVM IR and then to a native binary. Indentation makes blocks. There is no null and there are no exceptions. Every code block below is a whole program, and every one of them is compiled by tools/docs_check.sh — if a sample here stops working, the build says so.

1. Hello

fn main() -> int:
    print_line("hello")
    0

Build and run it:

dist/orion.exe hello.or hello.ll orbs
clang hello.ll runtime/orion_rt.c -o hello
./hello

A block's value is its last expression, so no return is needed — though return exists for leaving early. What main returns becomes the process exit code.

For anything larger than one file there is orbit: orbit new myapp, then orbit run, orbit build, orbit test.

2. Names

fn main() -> int:
    x = 41            # bound once
    mut total = 0     # this one changes
    total = total + x
    total += 1
    total

Plain = binds a new name. mut marks one you mean to reassign, and the compiler holds you to it. Types are inferred; write one when you want it checked, as in mut n: int = 0.

3. Text

fn main() -> int:
    name = "world"
    n = 3
    print_line("hello {name}, {n} times, {n * 2} in total")
    print_line("a literal brace: \{ and \}")
    0

Every string literal is an interpolation. A hole {...} takes any expression, not just a name. Escape a real brace as \{. Three or more parts compile to a single join, so building a line in a loop does not quietly cost you one allocation per piece.

4. Branching

fn classify(n: int) -> Text:
    match:
        n < 0:  "negative"
        n == 0: "zero"
        else:   "positive"

fn main() -> int:
    print_line(classify(0 - 5))
    label = if 1 == 1 then "yes" else "no"
    print_line(label)
    0

match: with no subject is a chain of conditions and the first true arm wins. It is what you use instead of else if. if c then a else b is the one-line form; the indented if c: / else: is the block form.

5. Loops

fn main() -> int:
    mut sum = 0
    loop i in 0..<5:                          # 0 1 2 3 4
        sum += i
    loop i in 1..=3:                          # 1 2 3
        sum += i
    doubled = loop x in [1, 2, 3]: x * 2      # [2, 4, 6]
    big = loop x in [1, 2, 3] where x > 1: x  # [2, 3]
    loop:
        break
    sum + len(doubled) + len(big)

loop is the only iteration keyword. In statement position it loops; in expression position it collects each body value into a list, which is where map and filter come from — where is the filter. 0..<5 excludes the end, 1..=3 includes it, and a bare loop: runs until break.

6. Lists and maps

fn main() -> int:
    xs = [10, 20, 30]
    ys = push(xs, 40)          # push returns a new list
    m = {"a": 1, "b": 2}
    print_line("first={xs[0]} len={len(ys)} b={get(m, "b")}")
    xs[0] + len(ys)

push copies. That keeps value semantics unconditional, and it means x = push(x, v) in a tight loop is quadratic — for a hot accumulator, push_mut is the audited way to append in place. Index with xs[0]; at, len, get and has are the function forms, all built in and needing no import.

7. Types

type Player: name: Text, hp: int

type Shape:
    Circle(int)
    Rect(int, int)

fn area(s: Shape) -> int:
    match s:
        Circle(r) -> 3 * r * r
        Rect(w, h) -> w * h

fn main() -> int:
    p = Player{name: "Hero", hp: 100}
    print_line("{p.name} has {p.hp} hp")
    area(Shape.Rect(6, 7))

One keyword for both shapes. Fields on a line make a record, reached with p.name. Variants make a sum type, built as Shape.Rect(6, 7) and read by match, which is checked for exhaustiveness. _ is the catch-all pattern, and if let Circle(r) = s: handles the single-case check without a full match.

8. Functions, lambdas, orbs

use text
use iter

fn main() -> int:
    words = split("alpha,beta,gamma", ",")
    lengths = loop w in words: len(w)
    double = fn(x): x * 2
    print_line("words={len(words)} letters={sum(lengths)}")
    double(21)

A library is an orb: use text brings one in, and pub fn is what an orb exports. Each orb is its own namespace. A lambda is fn(params): body and closes over what it needs. Any function can also be called method-style, so trim(s) and s.trim() are the same call.

9. When it goes wrong

type Result: Ok(int), Err(Text)

fn safe_div(a: int, b: int) -> Result:
    if b == 0:
        Result.Err("divide by zero")
    else:
        Result.Ok(a / b)

fn calc(x: int) -> Result:
    v = safe_div(84, x)?      # unwrap, or return the Err
    Result.Ok(v * 2)

fn main() -> int:
    require 1 == 1            # traps if false
    defer print_line("cleanup runs last")
    match calc(2):
        Ok(v) -> v
        Err(_) -> 0

There is no null to forget to check and no exception to forget to catch. Failure is a value: give it a variant, and ? either unwraps the good case or returns the bad one to your caller. require and ensure are runtime contracts that trap on a false condition. defer runs at block end, last registered first, and before any return.
